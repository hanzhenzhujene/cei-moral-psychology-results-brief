# Visual results

[Open the PDF](cei-moral-psychology-results-full-deck.pdf) · [Download the PowerPoint](cei-moral-psychology-results-full-deck.pptx) · [Open all rendered figures](full-rendered/)

The 33-slide deck is the complete results page. Each slide states one finding and includes speaker notes with context, interpretation, limits, and sources.

| Slides | Focus |
|---:|---|
| 1–8 | Main findings and evidence status |
| 9–20 | Task results, uncertainty, model size, and release timing |
| 21–26 | Paper questions, reported results, and CEI fit |
| 27–31 | Enlarged result charts |
| 32–33 | Next steps and final decision |

Papers: [MoralBench](https://arxiv.org/pdf/2406.04428v2) · [UniMoral](https://aclanthology.org/2025.acl-long.294.pdf) · [MoReBench](https://arxiv.org/pdf/2510.16380v2) · [MoralLens](https://aclanthology.org/2025.emnlp-main.1563.pdf) · [Value Kaleidoscope](https://arxiv.org/pdf/2309.00779v2)

Paper and CEI scores remain separate. None of the CEI tests is documented as an exact repeat of a paper experiment.
